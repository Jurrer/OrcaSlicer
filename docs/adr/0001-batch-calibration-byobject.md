# Batch calibration uses ByObject print sequence

Batch calibration calibrates multiple loaded filaments on a single plate in one G-code file. We chose ByObject (sequential) print sequence as the default, not ByLayer, because ByObject prints each filament's test fully before moving to the next — clean filament isolation with no interleaving. The trade-off: ByObject requires `extruder_clearance_radius` spacing (default 40 mm) between objects, which may make it difficult to fit all tests on one plate. ByLayer is compact but causes filament changes on every layer and is not the intended use case; it is offered as a fallback with a warning.

## Filament-change compatibility

Batch calibration reuses the printer's configured filament-change behavior. It does not add batch-specific purge blocks, timed pauses, filament-swap logic, or direct tool-switch G-code. AMS and other automated systems therefore keep receiving the standard tool-change command generated by `GCodeWriter`. Manual, non-AMS systems enabled with `manual_filament_change` keep the existing manual-change marker, which the printer's existing pause/resume and filament-swap workflow interprets. Single-physical-extruder, multi-filament configurations also use that marker instead of a batch-specific command.

Manual verification is required on each relevant hardware type before a release: slice a two-filament batch, confirm an automated AMS system changes filament once between tests and completes both tests, then repeat with `manual_filament_change` enabled and perform the firmware's pause, load, and resume workflow. For a single physical extruder configured for multiple filaments, confirm the marker pauses at the expected test boundary and that loading filament 2 resumes the correct test without an extra purge or timed wait.

The printer's `extruder_clearance_radius` is respected as-is and never silently overridden, since reducing it below the real toolhead dimensions could cause physical crashes. The short-objects exemption (`is_all_objects_are_short()`) applies automatically: if all test patterns are shorter than `nozzle_height` (default 2.5 mm), clearance drops to `MAX_OUTER_NOZZLE_DIAMETER` (4 mm). This benefits PA Line (single-layer) but not PA Pattern or Flow Ratio (multi-layer).
